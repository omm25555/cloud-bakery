# Game Design Document: Cloud Bakery

## สรุปเกม
**Cloud Bakery: เบเกอรี่ลอยฟ้า** เป็นเกม Roblox แนว cozy co-op bakery simulation บนเกาะลอยฟ้า

## วงจรหลัก
เก็บเกี่ยว (Harvest) → อบขนมพร้อมมินิเกมจังหวะ (Bake) → เสิร์ฟออเดอร์ลูกค้าสัตว์ (Serve) → อัปเกรดร้าน (Upgrade)

## ขอบเขต MVP
- เกาะเดียว
- วัตถุดิบ 3 ชนิด: Wheat, StarMilk, Strawberry
- สูตร 3 สูตร: CloudBread, Croissant, StrawberryCake
- ลูกค้า NPC 3 ตัว: Panda, Fox, Bunny
- อัปเกรด 3 สาย
- บันทึกด้วย DataStore
- co-op แบบเบา

ตัวเลขทั้งหมดอยู่ใน `src/shared/Config` (ค่าเริ่มต้นเป็นค่าชั่วคราว รอปรับบาลานซ์ในเฟสท้าย)

## Visual & UI Reference
ภาพ concept จริงจะอยู่ใน `docs/concept/`

### 1. สไตล์ภาพรวม
- โทน pastel น่ารัก ชมพู ครีม ม่วงลาเวนเดอร์ ฟ้าอ่อน บรรยากาศอบอุ่น ผ่อนคลาย
- เกาะลอยฟ้าเหนือทะเลเมฆ มีน้ำตกไหลลงจากขอบเกาะ ดอกไม้ชมพูม่วงเต็มไปหมด เกาะปราสาทไกลๆ เป็นฉากหลัง
- ตัวละครสไตล์ Roblox ใส่หมวกเชฟสีขาวและผ้ากันเปื้อน

### 2. ผังเกาะหลัก (MVP)
- **Cloud Bakery**: อาคารร้านหลังคาชมพู กันสาดลายทาชมพูขาว ปล่องควันรูปหมวกเชฟ อยู่กลางเกาะ
- **Sky Garden**: สวนด้านซ้ายบน แปลงข้าวสาลีสีทอง ต้นไม้ผลเวทมนตร์ (ผลสีม่วงเรืองแสง) รั้วไม้ขาว
- **คอกวัว Star Milk**: วัวลายจุด ขวดนมมีดาวสีเหลือง ถังแก้วเก็บนมเรืองแสง
- **Mixing Table (โต๊ะผสม)**: โต๊ะไม้มีโหลแก้ววัตถุดิบ ชามผสม
- **Oven (เตาอบ)**: เตาอิฐทรงโดม มีไฟส้มข้างใน ปล่องควันด้านบน
- **Order Counter (จุดรับออเดอร์)**: ซุ้มกันสาดชมพู มีจอเก็บเงิน ตู้โชว์ขนมปัง ป้ายเมนูกระดานดำ
- **Serving Table (โต๊ะเสิร์ฟ)**: โต๊ะผ้าลายสก็อตชมพู เก้าอี้ไม้ ลูกค้าสัตว์นั่งกิน
- **Balloon Dock**: ท่าเรือสะพานไม้มุมซ้ายล่าง บอลลูนลายรุ้งพาสเทลมีหน้าเมฆยิ้ม (MVP เป็นจุดเกิดผู้เล่นและจุดที่ลูกค้าเดินเข้ามา ยังไม่ต้องเดินทางข้ามเกาะ)

### 3. UI / HUD
- **บนกลาง**: โลโก้ "Cloud Bakery: เบเกอรี่ลอยฟ้า" (เฉพาะหน้าโหลด/เมนู ไม่ค้างบน HUD)
- **ขวาบน**: เหรียญ (ไอคอนเหรียญทอง + ปุ่ม +) และ Reputation (ดาว + เลเวล + แถบความคืบหน้า)
- **ซ้ายบน**: แผง Daily Quest 3 ข้อ มี checkbox + progress (เช่น เก็บข้าวสาลี 30/30, อบขนมปังเมฆ 6/10, เสิร์ฟ 8 ออเดอร์ 3/8) และรางวัล (เหรียญ 500, ดาว 200)
- **ขวา**: แผง Orders การ์ดต่อลูกค้า รูปหน้าสัตว์ + ขนมที่สั่ง xจำนวน + หัวใจความพอใจ 3 ดวง + นาฬิกานับถอยหลัง (เช่น แพนด้า เค้กx2 2:45, สุนัขจิ้งจอก ครัวซองต์ x3 3:10, กระต่าย ขนมปังเมฆ x2 4:00)
- **ล่างขวา**: ปุ่มกลมมน 6 ปุ่ม Bag, Recipes, Upgrade (มีจุดแดงแจ้งเตือน), Pets, Decor, Settings
  - MVP ใช้ได้จริง 4 ปุ่ม (Bag, Recipes, Upgrade, Settings) ส่วน Pets/Decor แสดงแต่ล็อกไว้ "เร็วๆ นี้"
- **สไตล์ UI**: กรอบมนสีครีม หัวการ์ดสีม่วงเข้ม ตัวอักษรไทย + อังกฤษตัวเล็กในวงเล็บ (รองรับ 2 ภาษา)

### 4. Gameplay จากภาพ
- **เก็บเกี่ยว**: ข้าวสาลี, Star Milk (น้ำนมดาว), ผลไม้เวทมนตร์ (MVP ใช้สตรอว์เบอรีแทนได้)
- **ปรุงและอบ**: ผสมที่โต๊ะ แล้วอบด้วยมินิเกมจังหวะ แถบแนวนอนมีเส้นวิ่ง กดให้ตรงจุดดาวจะขึ้น "Perfect!" มีโน้ตดนตรีเด้ง
- **เสิร์ฟและตกแต่ง**: ลูกค้าสัตว์มี speech bubble รูปขนมที่อยากได้เหนือหัว
- **ลูกค้า**: แพนด้า, สุนัขจิ้งจอก (แว่นนักบิน), กระต่าย (หมวกฟาง) และเพนกวิน (ผ้าพันคอ เก็บไว้เฟสหลัง)

## ระบบในเวอร์ชันแรก (TASK-002)
ภาพจากการทดสอบใน Studio: [HUD](screenshots/v0.1-hud.jpg), [โต๊ะเสิร์ฟ](screenshots/v0.1-serve.jpg)

| ระบบ | ทำงานอย่างไร | ตัวเลขอยู่ที่ |
|---|---|---|
| เก็บเกี่ยว | แปลงข้าวสาลี 6 แปลง, พุ่มสตรอว์เบอรี 4 พุ่ม, วัว 2 ตัว กด ProximityPrompt เพื่อเก็บ แปลงใช้ร่วมกันทั้งเซิร์ฟเวอร์ เวลาโตนับที่ server | `Config/Crops`, `Config/World` |
| ผสม + มินิเกม | กดที่โต๊ะผสม → เลือกสูตร → server สุ่มจังหวะ 6 ดาว → client ส่งเวลากด → server ให้คะแนน Perfect / Good / พอใช้ (Perfect ได้ขนมเพิ่ม 1 ชิ้น) | `Config/Minigame` |
| เตาอบ | ขนมเข้าเตาตามเวลาอบของสูตร (อัปเกรดเตาลดเวลาและเพิ่มช่อง) กดที่เตาเพื่อเก็บ | `Config/Recipes`, `Config/Upgrades` |
| ลูกค้า | แพนด้า / สุนัขจิ้งจอก (แว่นนักบิน) / กระต่าย (หมวกฟาง) เดินจากท่าบอลลูนมานั่งที่โต๊ะเสิร์ฟ สูงสุด 3 ตัว หัวใจลดตามเวลา เสิร์ฟเร็วได้เหรียญมากกว่า | `Config/Customers` |
| อัปเกรด | สวน (+ผลผลิต), เตาอบ (เร็วขึ้น + ช่องอบ), หน้าร้าน (+ทิป) สายละ 5 เลเวล | `Config/Upgrades` |
| ชื่อเสียง / เลเวล | ได้จากการอบและเสิร์ฟ ปลดล็อก Croissant ที่ Lv.2 และ Strawberry Cake ที่ Lv.3 | `Config/Progression` |
| ภารกิจรายวัน | 3 ข้อ (เก็บข้าวสาลี 30, อบขนมปังเมฆ 10, เสิร์ฟ 8) ครบแล้วรับ 500 เหรียญ + 200 ชื่อเสียง รีเซ็ตทุกวัน (UTC) | `Config/Quests` |
| บันทึก | DataStore พร้อม retry, autosave, บันทึกตอนออกและ BindToClose ถ้าโหลดไม่ได้จะไม่บันทึกทับและแจ้งผู้เล่น | `Config/Game` |
| แจ้งเตือน | `NotifyService` (server) → `NotifyController` (client) ระบบเดียว รองรับไทย/อังกฤษ | `Locale.luau` |
