# Cloud Bakery: เบเกอรี่ลอยฟ้า (GDD ฉบับย่อ)

## ภาพรวม
- **แพลตฟอร์ม:** Roblox
- **แนวเกม:** cozy co-op bakery simulation
- **ฉาก:** เกาะลอยฟ้าเหนือทะเลเมฆ ผู้เล่นเปิดร้านเบเกอรี่เล็กๆ และค่อยๆ ขยายร้าน
- **อารมณ์:** สบาย ไม่กดดัน เล่นคนเดียวหรือกับเพื่อนก็ได้

## วงจรหลัก
```
Harvest → Bake → Serve → Upgrade → (วนกลับ)
```
1. **Harvest (เก็บเกี่ยว):** ปลูกและเก็บวัตถุดิบบนเกาะ พืชโตตามเวลาที่ server นับ
2. **Bake (อบ):** เอาวัตถุดิบมาทำตามสูตร แล้วเล่นมินิเกมจังหวะ ยิ่งกดตรงจังหวะ ขนมยิ่งคุณภาพดีและขายได้ราคาสูง
3. **Serve (เสิร์ฟ):** ลูกค้า NPC มาสั่งขนม เสิร์ฟถูกจะได้เหรียญ
4. **Upgrade (อัปเกรด):** ใช้เหรียญอัปเกรดร้าน 3 สาย

## ขอบเขต MVP
| หมวด | เนื้อหา |
|---|---|
| เกาะ | 1 เกาะ |
| วัตถุดิบ | Wheat, StarMilk, Strawberry |
| สูตร | CloudBread, Croissant, StrawberryCake |
| ลูกค้า NPC | Panda, Fox, Bunny |
| อัปเกรด | 3 สาย (ร่างไว้: ฟาร์ม, เตาอบ, หน้าร้าน) |
| บันทึก | DataStore (เหรียญ, วัตถุดิบ, เลเวลอัปเกรด, สูตรที่ปลดล็อก) |
| Multiplayer | co-op แบบเบา: เพื่อนเข้ามาช่วยเก็บ อบ และเสิร์ฟในร้านเดียวกันได้ |

ตัวเลขเบื้องต้นอยู่ที่ `src/shared/Config/` (Ingredients, Crops, Recipes) และจะปรับสมดุลภายหลัง

## สูตร (ค่าเริ่มต้น)
| สูตร | วัตถุดิบ | ปลดล็อก |
|---|---|---|
| CloudBread | Wheat ×2, StarMilk ×1 | Lv 1 |
| Croissant | Wheat ×3, StarMilk ×2 | Lv 2 |
| StrawberryCake | Wheat ×2, StarMilk ×2, Strawberry ×3 | Lv 3 |

## หลักการทางเทคนิค
- server เป็นผู้ตัดสินเหรียญ ของ รางวัล เวลาโต และผลมินิเกม (ดู `CLAUDE.md`)
- ค่าตัวเลขทั้งหมดอยู่ใน Config ไฟล์เดียว เพื่อให้ปรับสมดุลได้โดยไม่ต้องแตะ logic
